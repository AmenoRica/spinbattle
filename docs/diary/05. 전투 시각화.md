# 05. 전투 시각화

## 목표

전투 페이지에 CSS 애니메이션, Web Audio API 사운드, 리플레이 컨트롤을 구현하여 전투를 시각적·청각적으로 재현한다.

---

## 무엇을 만들었나

### CSS 애니메이션 (`battle_friendly.html` <style>)

10개의 키프레임 애니메이션을 정의했다:

| 애니메이션 | 용도 | 지속시간 |
|-----------|------|---------|
| `spin` | 팽이 회전 | `--spin-duration` 변수로 제어 |
| `wobbleStop` | 정지 시 흔들림→기울임→회색조 | 1.2s |
| `accelGlow` | 가속 시 황금빛 글로우 | 0.5s |
| `attackLunge` | 공격 시 돌진 | 0.35s |
| `hitWobble` | 피격 시 흔들림 | 0.4s |
| `critHit` | 크리티컬 시 강한 흔들림+섬광 | 0.5s |
| `endureAura` | 기합 발동 시 금빛 오라 | 0.8s |
| `winnerPulse` | 승리 시 황금빛 맥동 | 1.5s (무한반복) |
| `floatUp` | 부유 텍스트 (데미지 수치 등) | 1s |
| `sparkFly` | 스파크 파티클 | 0.4s |
| `slashSwipe` | 베기 이펙트 | 0.3s |

팽이 디스크는 `border-radius: 50%`와 `overflow: hidden`로 원형 이미지를 만들고, `animation: spin var(--spin-duration) linear infinite`로 회전시킨다. 속도가 변하면 JavaScript에서 `--spin-duration` 값을 변경한다.

### `BattleEffects` 모듈 (`battle-effects.js`)

DOM 조작으로 애니메이션 클래스를 추가/제거하는 IIFE 모듈이다.

```javascript
const BattleEffects = (() => {
    // 내부 상태: currentSpeed, maxSpeed
    function createFloatingText(side, text, color) { ... }
    function createSparks(side, color, count) { ... }
    // ...
    return {
        accel(side, oldSpeed, newSpeed) { ... },
        attack(attackerSide, defenderSide, crit) { ... },
        // ...
    };
})();
```

주요 기능:
- `updateSpeed(side, speed, max)`: CSS 변수와 속도 바를 업데이트
- `accel(side)`: 글로우 클래스 추가 + 부유 텍스트("가속!") + 스파크
- `attack(attacker, defender, crit)`: 돌진 애니메이션 + 120ms 후 피격 애니메이션 + 베기 이펙트
- `stop(side)`: `stopped` 클래스 추가 → `wobbleStop` 애니메이션 재생
- `battleEnd(winner)`: 승자에게 `spin-winner` 클래스 추가

### `BattleSound` 모듈 (`battle-sound.js`)

Web Audio API로 사운드를 합성하는 모듈이다. 오디오 파일 없이 모든 소리를 코드로 생성한다.

```javascript
const BattleSound = (() => {
    let ctx = null;
    let enabled = false;
    function playTone(freq, duration, type, volume, ramp) { ... }
    function playNoise(duration, volume) { ... }
    function playChord(freqs, duration, type, volume) { ... }
    return {
        init() { /* AudioContext는 사용자 제스처 후 생성 */ },
        toggle() { enabled = !enabled; ... },
        accel() { playTone(400, 0.15, "sine", 0.12, 800); },
        attack() { playNoise(0.12, 0.15); playTone(150, 0.08, "square", 0.06); },
        // ...
    };
})();
```

### `BattleReplay` 모듈 (`battle.js`)

전투 로그를 순차적으로 재생하는 컨트롤러다.

```javascript
const BattleReplay = (() => {
    let logData = [];
    let currentIndex = 0;
    let timer = null;
    let playing = false;
    let speed = 1;
    const BASE_INTERVAL = 600; // 기본 600ms per turn
    // ...
    return { init, play, pause, skip, restart, setSpeed, toggleSound };
})();
```

- **재생 속도**: 0.5x, 1x, 2x, 3x (BASE_INTERVAL을 speed로 나눔)
- **스킵**: 남은 모든 로그를 즉시 처리
- **리스타트**: 인덱스를 0으로 되돌리고 재생

## 어떤 문제를 겪었나

### 1. AudioContext 자동 재생 정책

브라우저는 사용자 제스처 없이 AudioContext를 생성하거나 resume하는 것을 차단한다. `BattleSound.init()`에서는 `ctx`를 생성하지 않고, `toggle()`에서 사용자가 클릭했을 때 생성하도록 지연시켰다. 사운드는 기본적으로 OFF(🔇)로 시작하며, 사용자가 버튼을 누르면 생성된다.

### 2. CSS 애니메이션과 JavaScript의 동기

`spin-disc.stopped` 클래스를 추가할 때 `animation: wobbleStop 1.2s ease-out forwards`가 기존 `spin` 애니메이션을 덮어써야 했다. `!important`를 사용하여 해결했다. 하지만 리스타트 시에는 `stopped` 클래스를 제거하고 `spin` 애니메이션을 복원해야 해서, `BattleEffects.reset()`에서 모든 임시 클래스를 제거하는 로직이 필요했다.

### 3. 팽이 크기와 이펙트 크기의 비율

처음에 팽이 크기를 350px로 설정했을 때, 스파크 파티클(6px, 이동거리 30-70px), 베기 이펙트(70px), 부유 텍스트(14px)가 팽이에 비해 너무 작아 보였다. 이펙트의 크기와 이동거리를 팽이 크기에 비례하도록 조정했다: 스파크 10px/50-120px, 베기 120px, 부유 텍스트 22px.

### 4. 한국어 하드코딩

초기에는 `battle-effects.js`에 `"가속!"`, `"인해!"` 등의 한국어 문자열이 하드코딩되어 있었다. 다국어 지원을 추가하면서 이를 `BattleI18n` 객체에서 불러오도록 변경했다. 템플릿에서 `{% trans %}`로 렌더링한 값을 JavaScript 객체에 주입하는 방식을 사용했다.

## 배운 점

- Web Audio API로 소리를 합성하면 오디오 파일이 필요 없지만, 브라우저의 자동 재생 정책을 항상 고려해야 한다. 사용자 제스처(클릭) 이후에만 AudioContext를 생성하는 것이 안전하다.
- CSS 애니메이션을 JavaScript에서 제어할 때는 클래스 추가/제거만으로도 충분한 경우가 많다. `!important`를 신중하게 사용하면 기존 애니메이션을 덮어쓸 수 있다.
- 전투 리플레이는 `setInterval` 기반의 간단한 스텝 방식으로 구현할 수 있다. 각 스텝에서 로그 엔트리의 `effects` 배열을 순회하며 적절한 애니메이션과 사운드를 디스패치한다.
