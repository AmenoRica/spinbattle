# 08. 카운트다운과 UX 다듬기

## 목표

전투 시작 전 3-2-1-시작! 카운트다운을 추가하여 긴장감을 조성하고, 음소거 상태를 localStorage에 저장하여 유지하며, 사운드 버튼을 상단바로 이동한다.

---

## 무엇을 만들었나

### 카운트다운 시퀀스

전투 페이지가 로드되면 팽이가 정지한 상태에서 3→2→1→시작! 카운트다운이 표시되고, 끝나면 팽이가 회전을 시작하며 전투 로그가 재생된다.

**구현 방식**:

1. `showCountdown(callback)` 함수가 화면 중앙에 카운트다운 오버레이를 표시한다.
2. 팽이 디스크에 `stopped` 클래스를 추가하여 회전을 멈춘다.
3. 속도 바를 0으로 설정한다.
4. 900ms 간격으로 "3" → "2" → "1" → "시작!"을 표시한다.
5. 각 단계에서 CSS 애니메이션(`countdownPulse`)을 재생한다.
6. "3/2/1"에서는 비프음(660Hz), "시작!"에서는 상승음(880→1320Hz)이 재생된다.
7. 카운트다운이 끝나면 `stopped` 클래스를 제거하고, `initSpeedBars()`로 속도를 설정한 후 `play()`로 전투를 시작한다.

**CSS**:
```css
@keyframes countdownPulse {
    0%   { transform: scale(0.3); opacity: 0; }
    30%  { transform: scale(1.3); opacity: 1; }
    70%  { transform: scale(1.0); opacity: 1; }
    100% { transform: scale(1.0); opacity: 0; }
}
```

**다국어**: "3", "2", "1"은 숫자이므로 언어 무관하게 표시하고, "시작!"만 `{% trans %}`로 번역한다. 한국어→시작!, 일본어→スタート!, 영어→Go!

### 음소거 상태 유지

`BattleSound` 모듈에서 `localStorage`를 사용하여 소리 on/off 상태를 유지한다.

```javascript
let enabled = localStorage.getItem("battleSound") === "on";

init() {
    const btn = document.getElementById("btn-sound");
    if (btn) btn.textContent = enabled ? "🔊" : "🔇";
}

toggle() {
    enabled = !enabled;
    localStorage.setItem("battleSound", enabled ? "on" : "off");
    if (enabled) getCtx();
    return enabled;
}
```

이전에는 소리가 기본 OFF였고 페이지 이동 시마다 리셋되었지만, 이제 한 번 🔊으로 켜면 재방문 시에도 소리가 켜진 상태로 유지된다.

### 사운드 버튼 위치 변경

전페이지의 사운드 버튼을 하단 컨트롤바에서 상단 헤더(SpinBattle 로고 옆)로 이동했다. 대전 모드 라벨과 나란히 배치하여 접근성을 높였다.

## 어떤 문제를 겪었나

### 1. 카운트다운 중 팽이가 회전하는 문제

초기 구현에서는 `initSpeedBars()`가 카운트다운 전에 호출되어 팽이가 이미 회전하고 있었다. 해결 방법:
- 카운트다운 시작 시 팽이에 `stopped` 클래스를 추가하고 속도를 0으로 설정
- 카운트다운 종료 시 `stopped` 클래스를 제거하고 `initSpeedBars()`를 호출
- 재시작(restart) 시에도 같은 패턴 적용

### 2. 사운드가 OFF인데 카운트다운 비프음이 들리는 문제

`BattleSound`의 `enabled` 상태를 확인하는 로직이 이미 `playTone()` 내부에 있으므로, `countdownBeep()`과 `countdownGo()`도 같은 `enabled` 체크를 거친다. OFF 상태에서는 소리가 나지 않는 것이 정상이다.

### 3. CSS 애니메이션 리플레이

같은 애니메이션을 다시 재생하려면 클래스를 제거했다가 다시 추가해야 한다. 하지만 브라우저는 같은 클래스를 연속해서 추가하면 애니메이션을 재실행하지 않는다. `void textEl.offsetWidth` 강제 리플로우 트릭을 사용하여 해결했다:

```javascript
textEl.classList.remove("animate-countdown-pulse");
void textEl.offsetWidth; // 강제 리플로우
textEl.classList.add("animate-countdown-pulse");
```

## 배운 점

- 카운트다운은 전투의 시작을 명확히 알리고 사용자에게 준비 시간을 준다. 게임 경험에서 "시작 전 대기"는 긴장감을 높이는 중요한 요소다.
- `localStorage`를 사용하면 사용자의 선호(소리 on/off)를 세션 간에 유지할 수 있다. 하지만 AudioContext는 여전히 사용자 제스처 후에만 생성할 수 있으므로, `localStorage`에 "on"이 저장되어 있어도 실제 소리는 사용자가 버튼을 누른 후에야 작동한다.
- CSS 애니메이션을 JavaScript에서 재실행하려면 강제 리플로우가 필요하다. `void element.offsetWidth`가 가장 간단한 방법이다.
